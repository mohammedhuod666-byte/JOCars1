## Data Flow Audit

### Current Data Flow

```
Listing Page → listing description → valuation request → valuation engine → comparable matching → valuation result
```

### Finding: "الوصف التفصيلي للإعلان" is LOST

| Step | Status |
|------|--------|
| Listing Page | Contains "الوصف التفصيلي للإعلان" field |
| Valuation Request | Does NOT include description |
| Valuation Engine | Does NOT receive description |
| Comparable Matching | Does NOT use description |

### Root Cause

1. **`VehicleSpec` interface** (`src/ai/valuation/types.ts`): No `description` field
2. **`buildSpecFromBody`** (`src/ai/valuation/request.ts`): Does not read `car.description` from database

### Impact

The valuation engine currently ignores valuable information in "الوصف التفصيلي للإعلان" such as:
- "BMW X5 40e X Drive" (variant confirmation)
- "Plug-in Hybrid" (powertrain confirmation)
- "2000cc" (engine size)
- "308HP" (power)
- "M Sport" (trim)
- "صيانة وكالة" (maintenance history)
- "مالك واحد" (ownership history)
- "دهان أصلي" (original paint)

### Recommendation (Future Fix)

Add `description` field to `VehicleSpec` and read it in `buildSpecFromBody`:

```typescript
// In types.ts
export interface VehicleSpec {
  // ... existing fields
  description?: string | null;  // "الوصف التفصيلي للإعلان"
}

// In request.ts (carId branch)
spec: {
  // ... existing fields
  description: car.description || null,
}
```

**Note:** This is a production code change and requires user approval before implementation.
